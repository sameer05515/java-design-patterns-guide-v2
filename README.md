# Java Design Patterns Study Guide — Expanded Edition

A static learning app built with HTML, Alpine.js, Tailwind CSS, Marked, and highlight.js.

## Run it
1. Extract the ZIP.
2. Run `python -m http.server 5500` in this folder.
3. Open http://localhost:5500.

Internet access is required because libraries are loaded from CDNs.

## Included content
- 23 classic Gang of Four patterns plus the Null Object idiom (clearly marked as an extra).
- Search across names, explanations, scenarios, structure, and trade-offs.
- Category filters: Creational, Structural, Behavioral, and Other.
- For each pattern: summary, intent, problem solved, structure, Java example, real-world scenario, use cases, benefits/trade-offs, related patterns, Spring/Java connection, interview note, and self-check questions.
- Copy example code and navigate between patterns.

## Notes
Examples are concise learning snippets, not full production implementations. Some snippets omit imports or surrounding application code for readability. Tailwind and other libraries are loaded via CDN for convenience; for production, bundle dependencies locally.
